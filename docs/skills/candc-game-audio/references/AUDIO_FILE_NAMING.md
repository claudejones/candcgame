# Audio File Naming

Use uppercase canonical IDs, underscores, no spaces. WAV is the archival master.

Stage music: `{STAGE_ID}_THEME.wav`.

Examples:
`NA02_THEME.wav`
`C_AND_C_TITLE.wav`
`WORLD_MAP.wav`
`SECRET_BOSS_THEME.wav`
`GAME_COMPLETE.wav`
`STAGE_COMPLETE.wav`
`CONTINENT_COMPLETE.wav`
`BOSS_COMPLETE.wav`

Functional SFX examples:
`PLAYER_JUMP.wav`
`PLAYER_LAND.wav`
`PLAYER_SLIDE.wav`
`PLAYER_HIT.wav`
`PLAYER_STUN.wav`
`PLAYER_RECOVER.wav`
`UI_SELECT.wav`
`UI_BACK.wav`
`UI_CONFIRM.wav`
`UI_ERROR.wav`
`STAGE_SELECT.wav`
`STAGE_UNLOCK.wav`
`CONTINENT_UNLOCK.wav`
`PLANE_FLYBY.wav`
`BOSS_GUN_CHARGE.wav`
`BOSS_GUN_FIRE.wav`
`BOSS_HIT.wav`
`BOSS_STUN.wav`

Prefix stage-specific hazard/ambience assets with stage ID when not globally reusable.
