# Suno Prompt Rules

## Advanced v6
Use for stage/title/world-map/boss/ending music.

Every production card: asset ID + filename; Advanced v6; Instrumental; target duration; BPM; key guidance; Styles; Exclude Styles; optional Weirdness/Style Influence; QA.

Default DNA: 8-bit/chiptune retro-console, playful adventure, forward momentum, catchy but gameplay-compatible melody, chip bass/drums, immediate start, enough variation for ~90 sec.

Common exclusions when appropriate:
`vocals, singing, orchestral, cinematic, ambient, lo-fi, rock guitars, modern EDM, slow intro, long breakdown, fade-out`

## Sounds — One Shot
Use for stingers and short SFX.
**Prompt must be ≤500 characters.**
Specify event/action, 8-bit family, function/emotion, sound shape, desired duration as guidance, and unwanted ambience/reverb/vocals when relevant.

## Sounds — Loop
Use mainly for ambience/repeating elements.
**Prompt must be ≤500 characters.**
QA: seam, repetition fatigue, masking, appropriate length.

## Observed results
- Sounds Loop test: ~21 sec.
- Advanced v6 NA01: ~1:52 and ~1:53; successful.
- Stage Complete One Shot: 10-sec and 7-sec candidates; 7-sec accepted.
