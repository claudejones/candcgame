# Bounded technical finishing

Applies to unapproved newly generated candidates, not accepted artwork. This operational policy implements the user's approved optimization plan; it does not relax image contracts or final visual acceptance.

1. Classify a failed check by file and defect. After the same defect occurs twice, diagnose its source before another generation. A configuration defect is fixed in configuration; valid artwork is not regenerated to compensate.
2. Reuse passing files. Regenerate only a file with an identified artistic/structural defect. Stop once it meets the brief and required checks.
3. A deterministic correction may address only a diagnosed mechanical defect while preserving authored visible content: a one-pixel canvas-width discrepancy without rescaling; alpha=1 residue in explicitly empty gutters; or an integer translation within a source cell, at most eight pixels, to align an existing contact/body anchor. Translation must retain every nontransparent pixel within its own cell and satisfy all gutters. Existing approved horizontal repeat-edge repair remains available under the landscape specification.
4. Never use this permission to reshape subjects, invent frontage, change apparent scale, crop visible art, move content across cells, repaint scenery or widen a playable band. Those are generation/art-direction tasks. Approved artwork requires the user's explicit revision scope. If the narrow correction cannot preserve visible content, stop it and use a focused generation/edit.
5. Record input/output hashes, operation and parameters once with the file result. Inspect the corrected image, alpha/source geometry and relevant composite/animation. Checks must run on corrected bytes. Retain the original generated candidate during the operation; durable selected bytes and evidence go to the recovery branch before an intentional stop.
6. A correction is not artwork approval, calibration or release. The editor receives provisional metadata and the user retains visual acceptance.

This policy removes repeated conversational approval for these bounded fixes during authorized new-asset production. It does not require an agent to transform an image with an unavailable or unsuitable tool; record a capability blocker rather than improvising a destructive repair.
