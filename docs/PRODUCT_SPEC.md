# Product Specification

Status: recovered high-level contract. Expand only from approved project decisions/source material.

## Product
Claude & Constance Around the World is a mobile-first landscape side-scrolling world-travel game featuring selectable Claude and Constance.

## Scope
- 7 continents
- 3 stages per continent
- 21 stages total

## Production platform
Mobile-first web application in landscape orientation. Final application architecture uses external assets/files in a maintainable directory structure rather than embedding all production image data in one HTML file.

## Content workflow
Stages are researched and specified before asset production. Each stage receives a vision direction, coordinated environment layers, stage objects/hazards and QA. A continent is integrated after all three of its stages have completed asset approval.

## Progression direction
Current locked direction: single campaign plus Perfect Runs. Each stage can award a stage medal; completing three medals supports a continent passport; 21 Perfects unlock a bonus level. Older Explorer/Adventurer UI may remain in the legacy harness and must be treated as historical implementation pending migration reconciliation, not automatically as current product direction.

## Quality principle
The repository specifications define production requirements. Legacy QA code is a behavioral reference, not the sole design authority. Approved visual/gameplay behavior must be preserved while architecture is cleaned up.
